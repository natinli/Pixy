# 使用说明

## 界面布局

- **左侧目录树**：与 Finder 目录结构一致，可展开/折叠、拖放移动文件
- **主区域**：缩略图浏览区，支持四种视图
- **工具栏**：前进/后退/上级、路径条（面包屑，可点击任意段跳转）、排序、缩略图尺寸、视图切换等
- 多标签页与多窗口：⌘T 新建标签页；⌘⇧T 恢复关闭的标签页；按住 ⌘ 可在后台打开新标签页

## 四种视图

| 视图 | 特点 |
|---|---|
| 自适应布局（Justified） | 行内按原始宽高比排列，行高一致，类似 Flickr |
| 瀑布流（Waterfall） | 固定列数，图片按原始比例放入最矮列 |
| 网格（Grid） | 固定方格，图片居中 |
| 列表（Detail） | 传统列表布局 |

切换：工具栏按钮或「更多」菜单；缩略图尺寸在工具栏调整。视图样式（边框、文件名显示、间距等）可在「设置 → 操作」中自定义并一键保存/切换配置。

## 图片浏览

### 缩略图模式

- **双击**：打开大图；双击文件夹进入目录
- **按住右键/左键 + 滚轮**：预览缩放
- **右键菜单**：打开方式、显示简介、标签、评级、复制粘贴等 Finder 式操作
- **选中**：单击选中；⇧ 范围选中；⌘ 多选
- 可见视频自动内联播放（可在设置中开关）

### 大图模式

- **滚轮**：缩放（可在设置中改为切换图像）
- **按住右键/左键 + 滚轮**：缩放
- **长按左键**：切换 100% 缩放；快捷键 Z 同效果
- **长按右键**：缩放到视图；快捷键 X 同效果
- **双击**：关闭大图，返回缩略图
- **拖动**：平移；放大后滚动可设为平移（"..." 菜单）
- **旋转/镜像**："..." 菜单；支持旋转锁定和缩放锁定
- **边缘点击**：点击左右边缘切换图像（可在设置开启）
- **"..." 按钮**：RAW 内嵌缩略图加速、锁定选项等
- **EXIF 信息**：自动显示，含 GPS
- **OCR/二维码**：文字识别（macOS 13.0+）与二维码识别、共享

## 右键手势

按住右键拖动后松开触发（轨迹有浮层提示）：

| 手势 | 动作 |
|---|---|
| 向右 | 下一个有图片/视频的文件夹（等同全盘排序后的下一个） |
| 向左 | 上一个有图片/视频的文件夹 |
| 向上 | 上级目录 |
| 向下 | 返回上一次的目录 |
| 向上右 | 平级的下一个有图片的文件夹 |
| 向下右 | 关闭当前标签页/窗口 |

## 键盘快捷键（常用）

### 目录导航

| 按键 | 动作 |
|---|---|
| W | 上级目录（同手势向上） |
| A / D | 上一个 / 下一个图片文件夹 |
| S | 返回历史（同手势向下） |

### 通用

| 按键 | 动作 |
|---|---|
| ⌘F | 搜索和过滤 |
| ⌘T / ⌘⇧T | 新建 / 恢复关闭的标签页 |
| ⌘C / ⌘V / ⌘X | 复制 / 粘贴 / 剪切 |
| Delete | 删除（⇧+Delete 永久删除） |
| Enter | 打开（用途可自定义） |
| Alt + Enter | 全屏 |
| 方向键 | 缩略图间导航 |
| Alt/⌘ + 方向键、PageDown | 大图翻页 |

快速搜索：直接键入文件名首字母可快搜（防抖）；支持中文拼音首字母搜索（设置开启）。

完整快捷键以「设置 → 操作」中的说明为准。

## 视频播放

- 缩略图区可见视频自动内联播放；列表模式支持连续播放
- 大图模式完整控制条：播放/暂停、进度拖拽、音量（记忆）、倍速
- **AB 循环**：指定 A/B 点循环播放片段
- 无音频轨视频正常播放

## 文件管理

- 操作方式与 Finder 一致：拖放（Option 拖动=复制）、右键菜单、快捷键
- 剪切（⌘X）+ 粘贴 = 移动；支持跨窗口/标签页拖放
- 「显示简介」统计选中项总大小等
- 批量重命名面板
- 「使用所选项目新建文件夹」
- 从照片、Safari 等应用拖入图片可直接保存
- 操作日志：菜单栏 → 编辑 → 操作日志

## Finder 标签与评级

- **标签**：缩略图悬停/右键打标，颜色与 Finder 同步；按标签过滤（支持与/或、反向）；可建自定义标签
- **评级**：XMP 星级写入文件元数据（无损）；按评级过滤和排序
- **增强索引**（设置开启）：自建标签索引，大幅加速大目录标签过滤

## 递归模式

「更多」菜单开启后，当前目录及所有子目录的图片合并显示；可配合排序与过滤。切换目录时保持递归状态可设置。

## 设置面板

| 页面 | 内容 |
|---|---|
| 通用 | 启动行为、滚动灵敏度、过滤保持、拼音搜索等 |
| 自定义 | 缩略图排除目录 |
| 标签 | 自定义标签管理、增强索引 |
| 高级 | 内存上限、缩略图线程数、搜索深度（内置/外置卷分开）、FFmpeg 开关 |
| 操作 | 全部快捷键与手势说明、视图样式配置 |

## 其他实用功能

- **收藏夹**：菜单栏收藏夹 + 弹窗管理，支持拖拽排序
- **便携模式**：窗口自动调整至图片大小
- **窗口置顶**、**窗口大小适配图片**
- **全屏**：工具栏自动隐藏、可隐藏鼠标指针
- **打印**、**视图截图**
- **随机文件夹缩略图**、文件夹缩略图叠放/平铺
- **RTL 布局**支持
