# 常见问题

## 安装与启动

### 打开提示「已损坏，无法打开」或「无法验证开发者」

应用未经 Apple 公证（签名），macOS Gatekeeper 会拦截，文件本身没有问题。两种解决方式：

1. 「系统设置 → 隐私与安全性」，找到被拦截的提示，点「仍要打开」。
2. 终端执行：

```bash
xattr -rd com.apple.quarantine /Applications/Pixy.app
```

### 首次启动看不到任何卷/目录

首次访问需要授权「文件与文件夹」或「完全磁盘访问」权限；在「系统设置 → 隐私与安全性」中为 Pixy 开启。

## 图片显示

### HDR 不生效？

HDR 显示需要 **macOS 14.0+** 且显示器支持 HDR。确认「更多」菜单中 HDR 选项已开启。

### RAW 文件缩略图加载慢

可在「更多」菜单开启「RAW 内嵌缩略图」，直接读取相机写入的内嵌预览，速度快但不是完整渲染。

### 部分图片缩略图空白/损坏提示

个别特殊编码（索引色、非常规 EXIF 方向）会走降级渲染路径，一般仍能显示；若始终失败，可能是文件本身损坏。

### 图片放大后模糊

Pixy 使用高质量缩放算法减轻摩尔纹；继续放大到 100%（长按左键）可看到原始像素。非整数缩放的锐度优化已内置。

## 视频播放

### 视频无法播放

- 确认「设置 → 高级」中 FFmpeg 开关状态；FFmpegKit 未加载时部分格式会静默降级
- 外部封装格式的支持取决于系统 AVFoundation 与内置 FFmpeg

### 想循环播放视频片段

大图模式控制条支持 AB 循环：设定 A、B 两点后循环播放该片段。

## 标签与评级

### 按标签过滤很慢

在「设置 → 标签」开启「增强索引」，首次扫描建索引后会大幅加速；此后文件增删移动会增量维护。

### 评级会不会改动图片文件？

评级以 XMP 元数据写入文件，**不重编码图像数据**，无画质损失。写入通过同卷隐藏临时文件原子替换完成。

## 性能

### 大目录（上万张）浏览卡顿？

- Pixy 对大目录做了增量布局与 LRU 内存回收，正常应保持流畅
- 可在「设置 → 高级」调低内存上限、调整缩略图线程数
- 「设置 → 自定义」可排除不需缩略图的目录（如巨型素材库）

### 外置卷/U 盘读取慢

「设置 → 高级」中外置卷的线程数与搜索深度是独立设置项，可按设备性能调整。

## 文件操作

### 删除的文件去哪了？

默认移到废纸篓；按住 **⇧ + Delete** 为永久删除。删除等操作可在「菜单栏 → 编辑 → 操作日志」中查看记录。

### 名称含有 `\` 的文件删除失败

此问题已在 1.7.5 修复，请升级版本。

### 从 Finder 打开路径含 `#` 或 `?` 的文件失败

此问题已在 1.3.1 修复，请升级版本。

## 其他

### 应用有网络请求吗？

没有。全部功能本地运行。

### 支持其他图片查看器的库功能吗？

支持菜单栏收藏夹与收藏夹弹窗，可分组管理常用目录。

### 如何恢复默认设置？

设置存储在 macOS 用户默认值（UserDefaults，键 `CustomStyle_v2_current` 等）；删除应用并清理对应偏好即可，或重装应用。
